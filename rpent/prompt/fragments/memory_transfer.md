A stored recipe is evidence about strategy, not a trajectory to replay.

- Take its phase order, observable gates, controller division, and recovery
  ideas. Protect relations the current run has already achieved.
- Rebind every object, destination, relation, arm choice, pixel, pose, height,
  clearance, grasp point, and release point from the current observations.
  Historical pixels, coordinates, and offsets are not targets.
- A supported recipe is the default skeleton; an experimental one is a weak
  prior.
- Single-seed evidence, however probable, does not establish cross-seed
  reliability.
- When a stored strategy stops fitting the scene, correct only the remaining
  blocker instead of restarting the task.
