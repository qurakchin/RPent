贡献指南
============

欢迎提交问题、修正文档或完善机器人与规划器集成。完整开发流程、代码风格和检查要求见仓库的 `CONTRIBUTING_zh.md <https://github.com/RLinf/RPent/blob/main/CONTRIBUTING_zh.md>`_。

.. page-head::
   :for: 要报告问题，或贡献代码、文档和平台集成的读者
   :outcome: 知道自己的改动适用哪套流程和检查
   :read-when: 准备提交拉取请求，或整理验证证据时
   :skip-when: 需要排查运行问题；见 :doc:`../guides/troubleshooting`

修改文档时，按 `文档风格指南 <https://github.com/RLinf/RPent/blob/main/docs/STYLE_GUIDE.md>`_ 同步维护中英文页面，并完成两种语言的严格构建。新增功能应说明实际验证范围。

扩展入口：:doc:`../development/add_robot`、:doc:`../development/add_primitive`、:doc:`../development/add_planner`。
